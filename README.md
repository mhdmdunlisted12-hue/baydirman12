# Şehir Kahramanları

Okuldaki akıllı tahtada oynanmak için yapılmış, tarayıcıda çalışan 3D aksiyon oyunu. Tek HTML dosyası, internet gerektirmez.

- **KANCA:** İple binalar arasında sallan, duvarlara tırman, düşmanları kendine çek.
- **ROKET:** Jet takımıyla uç, bomba bırak, enerji atışı yap.
- Dokunmatik kontroller + klavye/fare, grafik ayarları (Düşük / Orta / Yüksek / Ultra).

## Oynamak
`index.html` dosyasını indirip Firefox veya Chrome ile aç. Pardus, Windows ve macOS'ta çalışır.
